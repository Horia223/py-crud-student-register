# Student & Grades Management

This project was developed as part of my studies at Babeș-Bolyai University, Faculty of Mathematics and Computer Science, for the Fundamentals of Programming course.

I built it to practice Python, understand layered architecture, apply programming concepts learned during the course, and learn how to organize, test, and document a project using Git and GitHub.

## Features

- Manage students, disciplines, and grades
- Validate data and handle errors
- Search and filter records
- Generate statistics and student rankings
- Save and load data from text files
- Undo and redo operations

## Concepts & Technologies

- **Python Fundamentals** — variables, data types, control structures, functions, and modular programming
- **Object-Oriented Programming (OOP)** — classes, objects, encapsulation, and separation of responsibilities
- **Layered Architecture** — separating the application into Domain, Repository, Service, and UI layers
- **Data Structures and Algorithms** — working with collections, searching, filtering, sorting, and processing data
- **Validation and Exception Handling** — validating input and handling invalid operations using exceptions
- **Test-Driven Development (TDD)** — writing tests to verify functionality and guide implementation
- **Unit Testing** — testing individual components using Python's `unittest` module
- **File I/O and Data Persistence** — saving and loading application data from text files
- **Undo/Redo and State Management** — working with object references, shallow and deep copies, and restoring previous states


## Project Structure

- `Domain/` — entities and validators
- `Repository/` — data storage and file operations
- `Controller_Service/` — business logic and operations
- `UI/` — console interface
- `Tests/` — unit tests
- `Data/` — files used for data persistence

## How to Run

Make sure Python is installed, run the application from the project directory:

```bash
python app_coordinator.py
```

This is an educational project focused on learning and practicing programming fundamentals.
